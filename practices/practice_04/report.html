Практика 4: среда агента, skill и MCP

1. Настройка среды и применение

Добавлены правила AGENTS.md, конфиг .opencode/opencode.json, skill ai-app-smoke, локальный MCP ai-checker и плагин авто‑проверок.

  • AGENTS.md: правила, ссылки на эндпоинты и источники данных.
  • opencode.json: загрузка AGENTS.md, skill, MCP и плагина.
  • auto-check.js: после правки выполняет python -m py_compile для модулей бэкенда и сохраняет логи.
  • ai-checker (MCP): предоставляет tool'ы get_stats и validate_level.

Обоснование подключений: AGENTS.md — единые правила; skill — быстрый smoke для API; MCP — удобная статистика датасета и валидация уровня; плагин — раннее выявление синтаксических ошибок после правок.

2. Skill: ai-app-smoke

Skill автоматизирует проверку здоровья и выборки квиза. Содержит пошаговые команды запуска и негативный тест, требует сохранять артефакты в practices/practice_04/logs/. Результаты запусков подтверждены логами smoke.

См. файл: .opencode/skills/ai-app-smoke/SKILL.md

3. Собственный MCP: ai-checker

Реализован сервер JSON‑RPC поверх stdio на Python (.opencode/mcp/ai-checker/server.py).

  • get_stats — количество слов на каждом уровне из ai_app/backend/data/words.json.
  • validate_level — успех на корректном уровне и сигнал isError=true на ошибочном.

Подтверждения вызовов (успешный и ошибочный) в logs/mcp_calls.txt.

4. Автоматическая проверка

Плагин auto-check.js создаёт лог‑артефакт после правок. Пример артефакта smoke‑запуска:

HEALTH 200 {"status":"ok"}
QUIZ_OK 200 len=643
QUIZ_BAD_LEVEL HTTP Error 400: Bad Request
