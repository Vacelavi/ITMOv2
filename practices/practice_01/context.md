## Context Pack для первого рабочего сценария

### Факты и правила

- Вход ожидается как JSON с полем diff: string
- Выход: JSON {"comment": string}
- Текущая реализация использует dict без схемы и прямой доступ payload["diff"]
- Вызов внешнего сервиса LLM без обработки исключений

### Формат входа и результата

- Вход: {"diff": string}
- Результат: {"comment": string}

### Ограничения и запрещённые действия

- Нельзя: одобрять/merge; не добавлять новые «правила» политики; не удалять существующий текст из файлов
- Соблюдать формат: summary + ≤3 риска; каждый риск: candidate + evidence (file:line) + check

### Хороший пример

- Риск: candidate — «500 при POST {}», evidence — app/api.py:35-38 (payload: dict; payload["diff"]), check — POST /api/reviews с {} возвращает 500; ожидание — 422 при наличии схемы
### Плохой пример

- Риск без ссылок на файл/строки и без воспроизводимой проверки
### Что пока неизвестно

- Допустимый максимальный размер diff
- Ожидаемый код ошибки при падении LLM (4xx/5xx)

## Как использовали AI

- Для чего: базовое ревью TRAINING_PR.diff и фиксация рисков
- Тип промпта: zero-shot, роль AI-reviewer
- Строка в [`prompts.md`](prompts.md): P1-01
- Что проверили и исправили сами: проверка сценариев воспроизведения (описаны в checks); изменений в код не вносили в рамках этого шага
