## 4. Основной пользовательский сценарий

Два пользователя играют за одним экраном. Первый пользователь открывает каталог, выбирает Го напрямую или через описание, знакомится с правилами, задаёт имена и запускает партию. Игроки по очереди ставят камни или пасуют, видят текущего игрока и сообщения о невозможных действиях. После двух пасов отображаются результат, число ходов и продолжительность. Затем можно начать новую партию или вернуться в каталог.

Последовательность:

1. Загрузка каталога.
2. Выбор «Го».
3. Просмотр описания и правил либо быстрый запуск кнопкой «Играть».
4. Загрузка настроек через `GET /api/games/go`.
5. Игровая доска.
6. Два последовательных паса.
7. Результат партии.
8. «Сыграть ещё раз».
