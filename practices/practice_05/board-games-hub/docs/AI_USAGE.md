# Использование AI

## Инструменты

- **v0** — создание интерактивного макета каталога, диалога, игровой доски и результата.
- **Codex** — перенос опубликованного v0 в React/Vite, интеграция с FastAPI, подключение shadcn/ui, реализация игровой логики, доступности и клиентских тестов.
- **Vitest + Testing Library + user-event** — проверки видимого поведения интерфейса.

## Пример запроса для макета

> Создай адаптивный интерфейс Boardroom для двух пользователей за одним экраном. Сценарий: загрузка каталога → выбор Го → просмотр описания и правил → начало партии → загрузка → доска 9×9 → два паса → экран результата → сыграть ещё раз. Добавь состояния загрузки, пустого каталога и ошибки. Сохрани отдельную кнопку «Играть», которая запускает игру в обход описания. Используй shadcn/ui и сделай основной сценарий доступным с клавиатуры.

## Пример запроса для реализации

> Перенеси опубликованный интерфейс v0 в существующий React + Vite frontend. Не имитируй API таймерами: каталог должен использовать `GET /api/games`, а запуск — `GET /api/games/{game_id}`. Переиспользуй Button, Card, Dialog, Input, Label, Alert, Skeleton, Accordion, Badge и Separator из shadcn/ui. Добавь понятные ошибки, видимый focus, мобильную вёрстку и синхронную блокировку повторного submit.

## Пример запроса для тестов

> Предложи тесты видимого поведения для сценария Boardroom. Подмени ответы API тестовыми данными и проверь успех, пустой массив, задержанный Promise и ошибку. Проверь открытие и закрытие диалога, правила, обязательные и некорректные имена, повторную попытку и отсутствие второго запроса при двух submit во время ожидания. Добавь сквозной тест: каталог → быстрый запуск Го → два паса → результат → сыграть ещё раз → каталог.

## Что было исправлено после проверки AI-результата

- Сохранена намеренно добавленная пользователем кнопка быстрого запуска «Играть».
- Статические задержки прототипа заменены настоящими запросами FastAPI.
- Каталог и игровые состояния переведены на компоненты shadcn/ui.
- Добавлены подписи полей, проверка пустого имени, минимальной длины и одинаковых имён.
- Добавлена синхронная блокировка через `useRef`, поскольку одного `disabled` недостаточно для двух submit-событий в одном цикле React.
- Доска Го получила управление стрелками, Enter и пробелом, roving `tabIndex` и ссылку пропуска сетки.
- Сохранена настоящая логика захвата окружённых камней, которой не было в статическом прототипе.
- Упрощённая миниатюра нард была заменена точной структурой v0: две половины, 24 пункта, центральный бар и стопки шашек.
- После визуальной проверки исправлены геометрия доски Го и адаптивное отображение на узком экране.
- Тесты были изменены так, чтобы проверять видимый результат действий пользователя, а не внутреннее состояние React.

## Разделение вклада

AI подготовил варианты макета, компоненты, интеграционный код и первоначальные тесты. Пользователь определил основной сценарий и потребовал сохранить быстрый запуск. После совместной проверки были вручную уточнены соответствие v0, правила запуска, поведение нард, доступность и набор проверяемых состояний.
