# REPORT: Локальная модель для помощника по проекту

## Конфигурация железа

| Параметр | Значение |
|---|---|
| **ОС** | EndeavourOS Linux (Arch-based) |
| **Kernel** | 7.2.4-arch1-2 |
| **Архитектура** | x86_64 |
| **ОЗУ** | 32 ГБ |
| **GPU** | Встроенная (уточнить) |

## Параметры модели

| Параметр | Значение |
|---|---|
| **Модель** | Qwen 3.5:4B |
| **ID в Ollama** | `qwen:3.5-4b-instruct-q8_0` |
| **Квантизация** | Q8_0 (8-bit) |
| **Размер на диске** | ~2.8 ГБ |
| **Потребление ОЗУ** | ~4.5 ГБ при работе |
| **Контекст (основной)** | 4096 токенов |
| **Контекст (agent)** | 65536 токенов |

## Обоснование выбора

1. **Компромисс размер-качество**: 4B модель работает локально на среднем железе без GPU
2. **Инструктивность**: qwen-instruct хорошо следует инструкциям на русском
3. **Скорость**: генерирует ответ за 1-2 сек (vs 10+ для больших моделей)
4. **RAG-friendly**: хороший баланс между контекстным пониманием и скоростью
5. **OpenCode совместимость**: протестирована с вызовами через REST API

## Использованные конфигурации

### Modelfile (основной)
- num_ctx: 4096 (оптимально для быстрых Q&A)
- temperature: 0.2 (консервативные ответы)
- System prompt: ориентирован на работу с контекстом проекта

### Modelfile.agent
- num_ctx: 65536 (для полного просмотра кодовой базы)
- temperature: 0.2
- Система контроля: не выдумывать файлы, указывать источники
