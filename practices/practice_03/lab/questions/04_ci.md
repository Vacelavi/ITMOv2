# Вопрос 4

## Вопрос
Какая CI-система запускает тесты? Если сведений нет, скажи об этом.

## Эталонный ответ
В репозитории нет явной CI-системы для этого проекта. В коде и конфигурации не видно GitHub Actions, GitLab CI, Jenkins или других CI-подтяжек.

Проверяемый запуск — локальный через `make test`, и это описано в `lab/Makefile`:

```make
.PHONY: install test
install:
	@python3 -c "import sys; assert sys.version_info >= (3,10), 'Python 3.10+ required'; print('Standard library only: ready')"
test: install
	$(MAKE) -C demo test
```

То есть тесты запускаются локально, без отдельной CI-конфигурации в этом примере.

## Ответ локальной модели
Система CI не указана в предоставленных сведениях. "$(MAKE) -C demo test"
