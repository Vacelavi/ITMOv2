# Вопрос 5

## Вопрос
Сохраняются ли подписки после перезапуска процесса? Подтверди кодом.

## Эталонный ответ
Нет, подписки не сохраняются между перезапусками процесса. В `service.py` они хранятся в глобальном объекте `subscribers = set()`, который живёт только в памяти процесса.

Код:

```python
subscribers = set()
```

При перезапуске процесса объект создаётся заново, поэтому состояние теряется. В тестах это явно сбрасывается через:

```python
def setUp(self):
    subscribers.clear()
```

## Ответ локальной модели
Нет, подписки не сохраняются между перезапусками процесса. "subscribers = set()"/"subscribers.clear()"
